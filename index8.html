Inferno Forecast- Fire Prediction System

Machine Learning based fire risk prediction and real-time monitoring system using FastAPI, React, WebSockets, and geospatial visualization deployed on cloud platforms.

Problem Statement

Fire incidents cause environmental destruction and economic loss. Traditional systems are reactive and detect fires after occurrence. This project introduces a proactive machine learning-based system for predicting fire risk and enabling real-time monitoring.

Literature Review

Random Forest models outperform linear models like Logistic Regression in wildfire prediction due to their ability to capture non-linear environmental interactions.

Research Gap

Most systems lack real-time deployment and integration with cloud-based APIs. This project bridges that gap.

System Methodology

Inputs

Temperature, Humidity, Wind Speed, Vegetation Index, GPS Coordinates
